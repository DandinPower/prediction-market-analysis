## [​](https://docs.polymarket.com/cn/market-data/websocket/market-channel\#%E8%AE%A2%E9%98%85)  订阅

复制

询问AI

```
{
  "assets_ids": ["<token_id_1>", "<token_id_2>"],
  "type": "market",
  "custom_feature_enabled": true
}
```

设置 `custom_feature_enabled: true` 以接收 `best_bid_ask`、`new_market` 和 `market_resolved` 事件。

## [​](https://docs.polymarket.com/cn/market-data/websocket/market-channel\#%E6%B6%88%E6%81%AF%E7%B1%BB%E5%9E%8B)  消息类型

每条消息都包含一个 `event_type` 字段来标识类型。

### [​](https://docs.polymarket.com/cn/market-data/websocket/market-channel\#book)  book

首次订阅市场时以及发生影响订单簿的交易时触发。

询问AI

```
  "asset_id": "65818619657568813474341868652308942079804919287380422192892211131408793125422",
  "market": "0xbd31dc8a20211944f6b70f31557f1001557b59905b7738480ca09bd4532f84af",
  "bids": [\
    { "price": ".48", "size": "30" },\
    { "price": ".49", "size": "20" },\
    { "price": ".50", "size": "15" }\
  ],
  "asks": [\
    { "price": ".52", "size": "25" },\
    { "price": ".53", "size": "60" },\
    { "price": ".54", "size": "10" }\
  ],
  "timestamp": "123456789000",
  "hash": "0x0...."
}
```

### [​](https://docs.polymarket.com/cn/market-data/websocket/market-channel\#price_change)  price\_change

下新订单或取消订单时触发。

复制

询问AI

```
{
  "market": "0x5f65177b394277fd294cd75650044e32ba009a95022d88a0c1d565897d72f8f1",
  "price_changes": [\
    {\
      "asset_id": "71321045679252212594626385532706912750332728571942532289631379312455583992563",\
      "price": "0.5",\
      "size": "200",\
      "side": "BUY",\
      "hash": "56621a121a47ed9333273e21c83b660cff37ae50",\
      "best_bid": "0.5",\
      "best_ask": "1"\
    },\
    {\
      "asset_id": "52114319501245915516055106046884209969926127482827954674443846427813813222426",\
      "price": "0.5",\
      "size": "200",\
      "side": "SELL",\
      "hash": "1895759e4df7a796bf4f1c5a5950b748306923e2",\
      "best_bid": "0",\
      "best_ask": "0.5"\
    }\
  ],
  "timestamp": "1757908892351",
  "event_type": "price_change"
}
```

`size` 为 `"0"` 表示该价格级别已从订单簿中移除。

### [​](https://docs.polymarket.com/cn/market-data/websocket/market-channel\#tick_size_change)  tick\_size\_change

市场的最小价格变动单位发生变化时触发。当订单簿价格达到极限值时会发生这种情况：price > 0.96 或 price < 0.04。

复制

询问AI

```
{
  "event_type": "tick_size_change",
  "asset_id": "65818619657568813474341868652308942079804919287380422192892211131408793125422",
  "market": "0xbd31dc8a20211944f6b70f31557f1001557b59905b7738480ca09bd4532f84af",
  "old_tick_size": "0.01",
  "new_tick_size": "0.001",
  "timestamp": "100000000"
}
```

```
  "price": "0.456",
  "side": "BUY",
  "size": "219.217767",
  "timestamp": "1750428146322"
}
```

```
  "best_bid": "0.73",
  "best_ask": "0.77",
  "spread": "0.04",
  "timestamp": "1766789469958"
}
```
