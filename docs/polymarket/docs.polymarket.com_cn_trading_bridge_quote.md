在执行充值或提现前获取预估报价。报价包括预估输出金额、结算时间和详细的费用明细。

## [​](https://docs.polymarket.com/cn/trading/bridge/quote\#%E8%8E%B7%E5%8F%96%E6%8A%A5%E4%BB%B7)  获取报价

复制

询问AI

```
curl -X POST https://bridge.polymarket.com/quote \
  -H "Content-Type: application/json" \
  -d '{
    "fromAmountBaseUnit": "10000000",
    "fromChainId": "137",
    "fromTokenAddress": "0x3c499c542cEF5E3811e1192ce70d8cC03d5c3359",
    "recipientAddress": "0x17eC161f126e82A8ba337f4022d574DBEaFef575",
    "toChainId": "137",
    "toTokenAddress": "0x2791Bca1f2de4661ED88A30C99A7a9449Aa84174"
  }'
```

### [​](https://docs.polymarket.com/cn/trading/bridge/quote\#%E8%AF%B7%E6%B1%82%E5%8F%82%E6%95%B0)  请求参数

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `fromAmountBaseUnit` | string | 要发送的金额(基本单位)，例如 `"10000000"` 代表 10 USDC |
| `fromChainId` | string | 源链 ID，例如 `"137"` 代表 Polygon |
| `fromTokenAddress` | string | 源链上的代币合约地址 |
| `recipientAddress` | string | 接收资金的目标钱包地址 |
| `toChainId` | string | 目标链 ID |
| `toTokenAddress` | string | 目标链上的代币合约地址 |

### [​](https://docs.polymarket.com/cn/trading/bridge/quote\#%E5%93%8D%E5%BA%94)  响应

报价响应包括:

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `estCheckoutTimeMs` | number | 预估结算时间(毫秒) |
| `estInputUsd` | number | 预估输入价值(美元) |
| `estOutputUsd` | number | 预估输出价值(美元) |
| `estToTokenBaseUnit` | string | 预估输出金额(基本单位) |
| `quoteId` | string | 此报价的唯一标识符 |
| `estFeeBreakdown` | object | 详细费用明细(见下文) |

### [​](https://docs.polymarket.com/cn/trading/bridge/quote\#%E8%B4%B9%E7%94%A8%E6%98%8E%E7%BB%86)  费用明细

`estFeeBreakdown` 对象包含:

gasUsd

number

Gas 费(美元)

[​](https://docs.polymarket.com/cn/trading/bridge/quote#param-app-fee-label)

appFeeLabel

string

应用费用标签

[​](https://docs.polymarket.com/cn/trading/bridge/quote#param-app-fee-percent)

appFeePercent

number

应用费用占总金额的百分比

[​](https://docs.polymarket.com/cn/trading/bridge/quote#param-app-fee-usd)

appFeeUsd

number

应用费用(美元)

[​](https://docs.polymarket.com/cn/trading/bridge/quote#param-fill-cost-percent)

fillCostPercent

number

执行成本占总金额的百分比

[​](https://docs.polymarket.com/cn/trading/bridge/quote#param-fill-cost-usd)

fillCostUsd

number

执行成本(美元)

[​](https://docs.polymarket.com/cn/trading/bridge/quote#param-max-slippage)

maxSlippage

number

最大潜在滑点百分比

[​](https://docs.polymarket.com/cn/trading/bridge/quote#param-min-received)

minReceived

number

扣除滑点后收到的最小金额

[​](https://docs.polymarket.com/cn/trading/bridge/quote#param-swap-impact)

swapImpact

number

兑换影响占总金额的百分比

[​](https://docs.polymarket.com/cn/trading/bridge/quote#param-swap-impact-usd)

swapImpactUsd

number

兑换影响(美元)

[​](https://docs.polymarket.com/cn/trading/bridge/quote#param-total-impact)

totalImpact

number

总影响占总金额的百分比

[​](https://docs.polymarket.com/cn/trading/bridge/quote#param-total-impact-usd)

totalImpactUsd

number

总影响成本(美元)
