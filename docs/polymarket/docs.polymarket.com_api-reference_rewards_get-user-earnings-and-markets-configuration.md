string

header

required

Unix timestamp of the request

#### Query Parameters

[​](https://docs.polymarket.com/api-reference/rewards/get-user-earnings-and-markets-configuration#parameter-date)

date

string<date>

Date in YYYY-MM-DD format. Defaults to current date if not provided.

[​](https://docs.polymarket.com/api-reference/rewards/get-user-earnings-and-markets-configuration#parameter-signature-type)

signature\_type

enum<integer>

Signature type for address derivation (required for API KEY auth):

- 0: EOA
- 1: POLY\_PROXY
- 2: POLY\_GNOSIS\_SAFE

Available options:

`0`,

`1`,

`2`

[​](https://docs.polymarket.com/api-reference/rewards/get-user-earnings-and-markets-configuration#parameter-maker-address)

maker\_address

string

Maker address to query data for

[​](https://docs.polymarket.com/api-reference/rewards/get-user-earnings-and-markets-configuration#parameter-sponsored)

sponsored

boolean

default:false

If true, returns sponsored reward earnings

[​](https://docs.polymarket.com/api-reference/rewards/get-user-earnings-and-markets-configuration#parameter-next-cursor)

next\_cursor

string

Pagination cursor from previous response

[​](https://docs.polymarket.com/api-reference/rewards/get-user-earnings-and-markets-configuration#parameter-page-size)

page\_size

integer

default:100

Number of items per page (max 500, values above are capped)

Required range: `x <= 500`

[​](https://docs.polymarket.com/api-reference/rewards/get-user-earnings-and-markets-configuration#parameter-q)

q

string

Search query to filter markets by question/description

[​](https://docs.polymarket.com/api-reference/rewards/get-user-earnings-and-markets-configuration#parameter-tag-slug)

tag\_slug

string

Filter by tag slug (can be repeated for OR logic)

[​](https://docs.polymarket.com/api-reference/rewards/get-user-earnings-and-markets-configuration#parameter-favorite-markets)

favorite\_markets

boolean

default:false

If true, only show markets favorited by the user (requires auth)

[​](https://docs.polymarket.com/api-reference/rewards/get-user-earnings-and-markets-configuration#parameter-no-competition)

no\_competition

boolean

default:false

Filter for markets with no competition

[​](https://docs.polymarket.com/api-reference/rewards/get-user-earnings-and-markets-configuration#parameter-only-mergeable)

only\_mergeable

boolean

default:false

Filter for only mergeable markets

[​](https://docs.polymarket.com/api-reference/rewards/get-user-earnings-and-markets-configuration#parameter-only-open-orders)

only\_open\_orders

boolean

default:false

Filter for markets where user has open orders

[​](https://docs.polymarket.com/api-reference/rewards/get-user-earnings-and-markets-configuration#parameter-only-open-positions)

only\_open\_positions

boolean

default:false

Filter for markets where user has open positions

`end_date`,

`earnings`,

`spread`,

`competitiveness`,

`question`,

`price`,

`market`,

`ASC`,

`DESC`
