## [​](https://docs.polymarket.com/resources/error-codes\#global-errors)  Global Errors

These errors can occur on **any authenticated endpoint**.

[​](https://docs.polymarket.com/resources/error-codes#param-401)

401

Unauthorized

`Unauthorized/Invalid api key` — Your API key is missing, expired, or invalid. Ensure you’re sending all required [authentication headers](https://docs.polymarket.com/trading/overview#authentication).

[​](https://docs.polymarket.com/resources/error-codes#param-401-1)

401

Unauthorized

`Invalid L1 Request headers` — Your L1 authentication headers (HMAC signature) are malformed or the signature doesn’t match. See [Authentication](https://docs.polymarket.com/api-reference/authentication).

[​](https://docs.polymarket.com/resources/error-codes#param-503)

503

Service Unavailable

`Trading is currently disabled. Check polymarket.com for updates` — The exchange is temporarily paused. No orders (including cancels) are accepted.

[​](https://docs.polymarket.com/resources/error-codes#param-503-1)

503

Service Unavailable

`Trading is currently cancel-only. New orders are not accepted, but cancels are allowed.` — The exchange is in cancel-only mode. You can cancel existing orders but cannot place new ones.

[​](https://docs.polymarket.com/resources/error-codes#param-429)

429

Too Many Requests

`Too Many Requests` — You’ve exceeded the [rate limit](https://docs.polymarket.com/api-reference/rate-limits). Back off and retry with exponential backoff.

[​](https://docs.polymarket.com/resources/error-codes#param-400-19)

400

Bad Request

`Too many orders in payload: {N}, max allowed: {M}` — The batch contains more orders than the maximum allowed per request.

## [​](https://docs.polymarket.com/resources/error-codes\#order-processing-errors)  Order Processing Errors

These errors are returned when an order passes initial validation but fails during processing. They appear in the response body of `POST /order` and `POST /orders`.

[​](https://docs.polymarket.com/resources/error-codes#param-400-20)

400

Bad Request

`invalid post-only order: order crosses book` — A post-only (maker) order would immediately match. Adjust the price so it rests on the book.

[​](https://docs.polymarket.com/resources/error-codes#param-400-21)

400

Bad Request

`order {id} is invalid. Price ({price}) breaks minimum tick size rule: {tick}` — The order price doesn’t align with the market’s tick size. Use [`GET /tick-size`](https://docs.polymarket.com/api-reference/clob#get-tick-size) to check the valid tick size.

[​](https://docs.polymarket.com/resources/error-codes#param-400-22)

400

Bad Request

`order {id} is invalid. Size ({size}) lower than the minimum: {min}` — The order size is below the market minimum.

[​](https://docs.polymarket.com/resources/error-codes#param-400-23)

400

Bad Request

`order {id} is invalid. Duplicated.`

[​](https://docs.polymarket.com/resources/error-codes#param-400-24)

400

Bad Request

`order {id} crosses the book`

[​](https://docs.polymarket.com/resources/error-codes#param-400-25)

400

Bad Request

`not enough balance / allowance` — Insufficient USDC.e balance or token allowance. Check your balance with [`GET /balance-allowance`](https://docs.polymarket.com/api-reference/clob#get-balance-allowance) and approve the exchange contract if needed.

[​](https://docs.polymarket.com/resources/error-codes#param-400-26)

400

Bad Request

`invalid nonce` — The order nonce has already been used or is invalid.

[​](https://docs.polymarket.com/resources/error-codes#param-400-27)

400

Bad Request

`invalid expiration` — The order expiration timestamp is in the past or invalid.

[​](https://docs.polymarket.com/resources/error-codes#param-400-28)

400

Bad Request

`order canceled in the CTF exchange contract`

[​](https://docs.polymarket.com/resources/error-codes#param-400-29)

400

Bad Request

`order match delayed due to market conditions`

[​](https://docs.polymarket.com/resources/error-codes#param-400-30)

400

Bad Request

`order couldn't be fully filled. FOK orders are fully filled or killed.` — A Fill-or-Kill order could not be completely filled by available liquidity. The entire order is rejected.

[​](https://docs.polymarket.com/resources/error-codes#param-400-31)

400

Bad Request

`no orders found to match with FAK order. FAK orders are partially filled or killed if no match is found.` — A Fill-and-Kill order found no matching orders at all. At least one match is required.

[​](https://docs.polymarket.com/resources/error-codes#param-400-32)

400

Bad Request

`the market is not yet ready to process new orders`

## [​](https://docs.polymarket.com/resources/error-codes\#matching-engine-errors)  Matching Engine Errors

Internal matching engine errors that may surface during order execution.

[​](https://docs.polymarket.com/resources/error-codes#param-425)

425

Too Early

The matching engine is restarting. Retry with exponential backoff. See [Matching Engine](https://docs.polymarket.com/trading/matching-engine) for details on restart schedule and handling.

[​](https://docs.polymarket.com/resources/error-codes#param-500)

500

Internal Server Error

`there are no matching orders`

[​](https://docs.polymarket.com/resources/error-codes#param-500-1)

500

Internal Server Error

`FOK orders are filled or killed` — A Fill-or-Kill order could not be fully satisfied.

[​](https://docs.polymarket.com/resources/error-codes#param-500-2)

500

Internal Server Error

`the trade contains rounding issues`

[​](https://docs.polymarket.com/resources/error-codes#param-500-3)

500

Internal Server Error

`the price of the taker's order has a discrepancy greater than allowed with the worst maker order`

## [​](https://docs.polymarket.com/resources/error-codes\#status-code-reference)  Status Code Reference

| Status | Meaning | Common Causes |
| --- | --- | --- |
| `400` | Bad Request | Invalid parameters, malformed payload, business logic violation |
| `401` | Unauthorized | Missing or invalid API key, bad HMAC signature, expired timestamp |
| `404` | Not Found | Market doesn’t exist, order not found, token ID not recognized |
| `425` | Too Early | Matching engine is restarting — retry with backoff. See [Matching Engine](https://docs.polymarket.com/trading/matching-engine) |
| `429` | Too Many Requests | Rate limit exceeded — implement exponential backoff |
| `500` | Internal Server Error | Unexpected server error — retry with backoff |
| `503` | Service Unavailable | Exchange paused or in cancel-only mode |

The CLOB API has an internal override: any error message containing `"not found"` returns `404`, `"unauthorized"` returns `401`, and `"context canceled"` returns `400`, regardless of the original status code.
