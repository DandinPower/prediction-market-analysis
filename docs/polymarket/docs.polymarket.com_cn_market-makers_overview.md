Polymarket 上的 Market Maker(做市商)是指通过持续发布买单和卖单来为预测市场提供流动性的交易者。通过设置价差,做市商让其他用户能够高效交易,同时赚取价差作为承担风险的补偿。做市商对 Polymarket 生态系统至关重要——他们为市场提供流动性、收紧价差以改善用户体验、通过持续报价实现价格发现,并吸收来自散户和机构用户的交易流。

**不是 Market Maker?** 如果你正在构建为用户路由订单的应用程序,请查看 [Builder Program](https://docs.polymarket.com/builders/overview)。

完成设置

部署钱包,充值 USDC.e,并设置代币授权。请参阅 [入门指南](https://docs.polymarket.com/market-makers/getting-started)。

2

[Navigate to header](https://docs.polymarket.com/cn/market-makers/overview#)

连接数据源

使用 WebSocket 获取实时订单簿更新,使用 Gamma API 获取市场元数据。请参阅 [市场数据](https://docs.polymarket.com/market-data/overview)。

3

[Navigate to header](https://docs.polymarket.com/cn/market-makers/overview#)

开始报价

通过 CLOB REST API 发布订单。请参阅 [交易](https://docs.polymarket.com/market-makers/trading)。
