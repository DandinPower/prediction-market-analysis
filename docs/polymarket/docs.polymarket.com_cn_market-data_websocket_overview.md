Polymarket 提供 WebSocket 频道，用于近实时流式传输订单簿数据、交易和个人订单活动。共有四个可用频道：`market`、`user`、`sports` 和 `RTDS`（Real-Time Data Socket）。

## [​](https://docs.polymarket.com/cn/market-data/websocket/overview\#%E9%A2%91%E9%81%93)  频道

| 频道 | 端点 | 需要认证 |
| --- | --- | --- |
| Market | `wss://ws-subscriptions-clob.polymarket.com/ws/market` | 否 |
| User | `wss://ws-subscriptions-clob.polymarket.com/ws/user` | 是 |
| Sports | `wss://sports-api.polymarket.com/ws` | 否 |
| [RTDS](https://docs.polymarket.com/market-data/websocket/rtds) | `wss://ws-live-data.polymarket.com` | 可选 |

### [​](https://docs.polymarket.com/cn/market-data/websocket/overview\#market-%E9%A2%91%E9%81%93)  Market 频道

| 类型 | 说明 | 自定义功能 |
| --- | --- | --- |
| `book` | 完整订单簿快照 | 否 |
| `price_change` | 价格级别更新 | 否 |
| `tick_size_change` | 最小价格变动单位变化 | 否 |
| `last_trade_price` | 交易执行 | 否 |
| `best_bid_ask` | 最优价格更新 | 是 |
| `new_market` | 新市场创建 | 是 |
| `market_resolved` | 市场判定 | 是 |

标记为”自定义功能”的类型需要在订阅时设置 `custom_feature_enabled: true`。

### [​](https://docs.polymarket.com/cn/market-data/websocket/overview\#user-%E9%A2%91%E9%81%93)  User 频道

| 类型 | 说明 |
| --- | --- |
| `trade` | 交易生命周期更新（MATCHED → CONFIRMED） |
| `order` | 订单下单、更新和取消 |

### [​](https://docs.polymarket.com/cn/market-data/websocket/overview\#sports)  Sports

| 类型 | 说明 |
| --- | --- |
| `sport_result` | 实时比赛分数、时段和状态 |

## [​](https://docs.polymarket.com/cn/market-data/websocket/overview\#%E8%AE%A2%E9%98%85)  订阅

连接后发送订阅消息以指定你想接收的数据。

### [​](https://docs.polymarket.com/cn/market-data/websocket/overview\#market-%E9%A2%91%E9%81%93-2)  Market 频道

复制

询问AI

```
{
  "assets_ids": [\
    "21742633143463906290569050155826241533067272736897614950488156847949938836455",\
    "48331043336612883890938759509493159234755048973500640148014422747788308965732"\
  ],
  "type": "market",
  "custom_feature_enabled": true
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `assets_ids` | string\[\] | 要订阅的代币 ID |
| `type` | string | 频道标识符 |
| `custom_feature_enabled` | boolean | 启用 `best_bid_ask`、`new_market` 和 `market_resolved` 事件 |

### [​](https://docs.polymarket.com/cn/market-data/websocket/overview\#user-%E9%A2%91%E9%81%93-2)  User 频道

复制

询问AI

```
{
  "auth": {
    "apiKey": "your-api-key",
    "secret": "your-api-secret",
    "passphrase": "your-passphrase"
  },
  "markets": ["0x1234...condition_id"],
  "type": "user"
}
```

`auth` 字段（`apiKey`、`secret`、`passphrase`） **仅在 user 频道中需要**。对于 market 频道，这些字段是可选的，可以省略。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `auth` | object | API 凭证（`apiKey`、`secret`、`passphrase`） |
| `markets` | string\[\] | 要接收事件的 condition ID |
| `type` | string | 频道标识符 |

user 频道通过 **condition ID**（市场标识符）订阅，而不是 asset ID。每个市场有一个 condition ID，但有两个 asset ID（Yes 和 No 代币）。

### [​](https://docs.polymarket.com/cn/market-data/websocket/overview\#sports-%E9%A2%91%E9%81%93)  Sports 频道

无需订阅消息。连接后即可开始接收所有活跃体育赛事的数据。

## [​](https://docs.polymarket.com/cn/market-data/websocket/overview\#%E5%BF%83%E8%B7%B3)  心跳

### [​](https://docs.polymarket.com/cn/market-data/websocket/overview\#market-%E5%92%8C-user-%E9%A2%91%E9%81%93)  Market 和 User 频道

每 10 秒发送一次 `PING`。服务器会响应 `PONG`。

复制

询问AI

```
PING
```

### [​](https://docs.polymarket.com/cn/market-data/websocket/overview\#sports-%E9%A2%91%E9%81%93-2)  Sports 频道

服务器每 5 秒发送一次 `ping`。你需要在 10 秒内响应 `pong`。

复制

询问AI

```
pong
```

如果你在 10 秒内没有响应服务器的 ping，连接将被关闭。

## [​](https://docs.polymarket.com/cn/market-data/websocket/overview\#%E6%95%85%E9%9A%9C%E6%8E%92%E9%99%A4)  故障排除

连接在打开后立即关闭

连接后立即发送有效的订阅消息。服务器可能会关闭在超时时间内未订阅的连接。

连接在约 10 秒后断开

你没有发送心跳。对于 market/user 频道，每 10 秒发送一次 `PING`；对于 sports 频道，用 `pong` 响应服务器的 `ping`。

未收到任何消息

1. 验证你的 asset ID 或 condition ID 是否正确 2. 检查市场是否处于活跃状态（未判定） 3. 如果期望接收 `best_bid_ask`、`new_market` 或 `market_resolved` 事件，请设置 `custom_feature_enabled: true`

认证失败 \- user 频道

验证你的 API 凭证是否正确且未过期。
