Polymarket 上的每个预测都由 **结果代币** 表示。当你交易时，你实际上在买卖这些代币。你的 **持仓** 就是你在某个市场中持有的代币余额。

![](https://mintcdn.com/polymarket-292d1b1b/FOMte3ewbG-LVy3k/images/core-concepts/token-lifecycle.png?fit=max&auto=format&n=FOMte3ewbG-LVy3k&q=85&s=cad279109c43c68c541123c2d348c4c5)![](https://mintcdn.com/polymarket-292d1b1b/FOMte3ewbG-LVy3k/images/dark/core-concepts/token-lifecycle.png?fit=max&auto=format&n=FOMte3ewbG-LVy3k&q=85&s=204d16c1d89892a3c8573060aa04780e)

## [​](https://docs.polymarket.com/cn/concepts/positions-tokens\#%E7%BB%93%E6%9E%9C%E4%BB%A3%E5%B8%81)  结果代币

每个市场有且仅有两种结果代币：

| 代币 | 可兑换金额 | 条件 |
| --- | --- | --- |
| **Yes** | $1.00 | 事件发生 |
| **No** | $1.00 | 事件未发生 |

代币是 Polygon 上的 **ERC1155** 资产，基于 [Gnosis Conditional Token Framework](https://github.com/gnosis/conditional-tokens-contracts/)（CTF）。它们完全在链上运行，是标准的 ERC1155 代币。

结果代币始终有完全的资金支撑。每一对已发行的 Yes/No 代币都有恰好 `$1` 的 USDC.e 抵押品锁定在 CTF 合约中。

### [​](https://docs.polymarket.com/cn/concepts/positions-tokens\#%E6%8B%86%E5%88%86-split)  拆分 \- Split

将 USDC.e 转换为结果代币。拆分 $1 可生成 1 个 Yes 代币和 1 个 No 代币。

复制

询问AI

```
$100 USDC.e → 100 个 Yes 代币 + 100 个 No 代币
```

适用于：

- 为做市创建库存
- 同时获取市场的两侧头寸

### [​](https://docs.polymarket.com/cn/concepts/positions-tokens\#%E4%BA%A4%E6%98%93-trade)  交易 \- Trade

在订单簿上买卖代币。这是大多数用户获取持仓的方式。

- 以 `$0.60` **买入 Yes** → 支付 `$0.60`，获得 1 个 Yes 代币
- 以 `$0.60` **卖出 Yes** → 交出 1 个 Yes 代币，获得 `$0.60`

你可以在判定结果公布前随时卖出持仓。

### [​](https://docs.polymarket.com/cn/concepts/positions-tokens\#%E5%90%88%E5%B9%B6-merge)  合并 \- Merge

将一组完整的代币转换回 USDC.e。合并需要等量的 Yes 和 No 代币。

复制

询问AI

```
100 个 Yes 代币 + 100 个 No 代币 → $100 USDC.e
```

适用于：

- 不通过交易退出持仓
- 将积累的代币转换回抵押品

### [​](https://docs.polymarket.com/cn/concepts/positions-tokens\#%E5%85%91%E6%8D%A2-redeem)  兑换 \- Redeem

市场判定结束后，将获胜代币兑换为 USDC.e。

| 结果 | Yes 代币 | No 代币 |
| --- | --- | --- |
| 事件发生 | 每个价值 $1 | 价值 $0 |
| 事件未发生 | 价值 $0 | 每个价值 $1 |

复制

询问AI

```
100 个获胜代币 → $100 USDC.e
```

### [​](https://docs.polymarket.com/cn/concepts/positions-tokens\#%E6%8C%81%E4%BB%93%E4%BB%B7%E5%80%BC)  持仓价值

你的持仓价值取决于当前市场价格：

复制

询问AI

```
持仓价值 = 代币数量 × 当前价格
```

假设你持有 100 个 Yes 代币，Yes 当前交易价为 $0.75：

复制

询问AI

```
持仓价值 = 100 × $0.75 = $75
```

## [​](https://docs.polymarket.com/cn/concepts/positions-tokens\#%E7%9B%88%E4%BA%8F)  盈亏

你的利润取决于市场判定结果与你的入场价格之间的差异。

### [​](https://docs.polymarket.com/cn/concepts/positions-tokens\#%E7%A4%BA%E4%BE%8B-%E4%BB%A5-0-40-%E4%B9%B0%E5%85%A5-yes)  示例 \- 以 0.40 买入 Yes

| 场景 | 结果 | 回报 | 盈亏 |
| --- | --- | --- | --- |
| 事件发生 | Yes 获胜 | $1.00 | 每个代币 +$0.60（150%） |
| 事件未发生 | No 获胜 | $0.00 | 每个代币 -$0.40（-100%） |

### [​](https://docs.polymarket.com/cn/concepts/positions-tokens\#%E6%8C%81%E4%BB%93%E5%A5%96%E5%8A%B1)  持仓奖励

Polymarket 根据你在符合条件的市场中的总持仓价值，支付 **年化 4.00%** 的持仓奖励。系统每小时随机采样一次你的持仓价值，奖励按天发放。利率为浮动利率，Polymarket 保留随时调整的权利。

### [​](https://docs.polymarket.com/cn/concepts/positions-tokens\#%E7%A4%BA%E4%BE%8B-%E5%88%A4%E5%AE%9A%E5%89%8D%E5%8D%96%E5%87%BA)  示例 \- 判定前卖出

你可以在市场判定结果公布前卖出，锁定利润或止损：

- 以 `$0.40` 买入 Yes
- 价格涨到 `$0.70`
- 以 `$0.70` 卖出 → 每个代币盈利 `$0.30`（75%）
